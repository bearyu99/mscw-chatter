# 글클메 채팅 번역기 설계

사용자가 한국어 또는 영어 텍스트를 복사하면, 사용자가 시작한 감시 세션에서 번역하고 클립보드에 번역문을 올린다. 입력을 복사할 수 있는 프로그램에서 동작한다. 게임 화면의 텍스트 선택·복사 기능, OCR, 키 입력 주입, 자동 전송은 제공하지 않는다.

Electron 메인 프로세스가 클립보드, 번역 API, 키 암호화, 트레이를 소유한다. React 화면에는 제한된 contextBridge API만 노출한다. Windows 10/11 x64와 macOS 13 이상을 대상으로 패키징하며 실제 호환성은 OS별 실행 검증이 필요하다.

실행 파일·번들 파일명은 `mscw-chatter`로 고정하고 사용자에게 표시하는 이름은 글클메 채팅 번역기를 사용한다. 한글 실행 파일명을 사용한 macOS 패키지의 시작 오류가 재현되어 실행 파일명을 분리했다. macOS 개발 빌드에는 hardened runtime과 기본 Electron 권한을 유지한 ad-hoc 서명을 적용한다.

1. 실행 시 감시는 꺼져 있다. 시작 시 기존 클립보드를 기준값으로 기록하고 새 복사부터 감지한다.
2. 250ms 간격으로 메인 프로세스에서 확인한다. 최신 입력이 오면 이전 요청을 취소하고 요청 번호로 늦은 응답을 차단한다.
3. 한글(자모 포함)이 있으면 한→영, 영문만 있으면 영→한이다. 혼합 문장과 고유명사에 대비해 방향을 수동 고정할 수 있다.
4. 용어집을 켜면 입력에 맞는 용어만 프롬프트에 포함한다. 끄면 용어집 지침도 제외한다. 숫자·수량·닉네임은 보존하도록 지시한다.
5. 번역 중 다른 내용을 복사했다면 결과는 기록에 남기되 클립보드를 덮어쓰지 않는다. 앱이 쓴 내용은 다시 번역하지 않는다. 자동 복사를 끌 수도 있다.
6. API 키는 화면으로 되돌려주지 않는다. Electron safeStorage로 암호화한 뒤 사용자 데이터 폴더에 저장한다. 암호화 저장이 불가능하면 키 저장을 거부한다.
7. 번역 기록은 메모리에 최대 50개만 보관하며 종료 시 사라진다. 클립보드 텍스트를 로그·설정 파일에 저장하지 않는다.

OpenAI Chat Completions, Anthropic Messages, Google generateContent, Ollama /api/chat, 로컬 OpenAI 호환 /v1/chat/completions를 별도 어댑터로 사용한다. 로컬 주소는 루프백에 한정한다. 클라우드 키는 고정된 제공자 주소로만 전송한다. 연결 테스트는 짧은 번역 요청을 보내므로 API 사용량이 발생할 수 있다. 모델 ID는 설정에서 직접 바꿀 수 있다.

화면은 번역·용어집·설정 세 곳이다. Pretendard는 패키지 안에 포함한다. 밝은 중립 배경과 따뜻한 코럴 강조색, 즉시 보이는 감시 상태, 복사 결과 피드백, 키보드 포커스, 축소 화면 대응을 적용한다. 브라우저 미리보기는 네이티브 기능과 구분해서 표시한다.

검증은 가짜 클립보드/HTTP 어댑터를 통한 경쟁 상태·무한 반복·취소·오류 테스트, 타입 검사, 프로덕션 빌드, Electron 실행과 로컬 모의 서버 통합 테스트를 포함한다. 모의 서버 성공을 실제 유료 API 번역 또는 Windows 게임 연동 성공으로 표현하지 않는다.
