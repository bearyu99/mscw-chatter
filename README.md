# 글클메 채팅 번역기

글로벌 클래식 메이플(MapleStory Classic World)에서 한국어와 영어로 대화하기 위한 데스크톱 클립보드 번역기입니다. Windows 10/11 x64와 macOS 13 이상을 대상으로 Electron, React, TypeScript로 구현했습니다. Pretendard를 앱에 포함하므로 폰트를 별도로 설치하지 않아도 됩니다.

## 시작하기

Node.js 24 LTS를 설치하고 프로젝트 폴더에서 다음 명령을 실행하세요.

```sh
npm ci
npm run dev
```

터미널에 로컬 개발 주소가 출력된 뒤 데스크톱 앱이 열립니다. 메인 프로세스의 코드를 변경하면 `npm run dev`를 다시 실행하세요. 화면 코드는 자동으로 반영됩니다.

1. **설정**에서 OpenAI, Anthropic, Google 또는 로컬 모델을 선택합니다.
2. 계정에서 사용할 수 있는 **모델 ID**와 개인 **API 키**를 입력하고 **설정 저장**을 누릅니다. 키를 이미 저장했다면 빈 입력은 기존 키를 유지합니다.
3. 필요하면 **연결 테스트**를 실행합니다. 짧은 번역 요청이므로 API 사용량이 발생할 수 있습니다. ChatGPT·Claude·Gemini 채팅 구독과 API 결제는 별도일 수 있으므로 API 계정에서 키·모델 접근 권한·사용량을 확인하세요.
4. **실시간 번역 → 번역 시작**을 누르고 번역할 문장을 복사합니다. 시작하기 전에 복사해 둔 텍스트는 자동 전송하지 않습니다.
5. **클립보드에 복사됨** 표시를 확인한 뒤 게임 채팅창에 붙여넣습니다.

게임 채팅이 텍스트 선택·복사를 지원하지 않으면 원문 입력창에 문장을 직접 입력하세요. 이 앱은 화면 인식(OCR), 게임 메모리 접근, 키 입력 주입 또는 채팅 자동 전송을 수행하지 않습니다. 복사 가능한 텍스트의 번역이 지원 범위입니다.

## 주요 기능

- 250ms 간격의 백그라운드 클립보드 감지, 한국어→영어 / 영어→한국어 자동 구분 및 수동 방향 고정
- OpenAI Chat Completions, Anthropic Messages, Google generateContent, Ollama, 로컬 OpenAI 호환 서버
- 메인 화면에서 게임 용어집 켜기·끄기, 62개 주요 용어 검색과 분류
- 번역문 자동 복사 또는 수동 복사, 직접 입력, 세션 번역 기록 최대 50개
- 최신 요청 우선 처리, 이전 요청 취소, 자체 복사 결과의 재번역 방지
- 번역 중 새로운 내용을 복사하면 그 내용을 보존하고 결과는 기록에서 수동 복사
- OS 암호화 저장소를 사용한 API 키 보호, 트레이 실행, 항상 위에 표시
- `Ctrl+Shift+Space`(Windows) / `Cmd+Shift+Space`(macOS)로 감시 켜기·끄기. 다른 앱이 사용 중이면 등록되지 않을 수 있으며 화면에 대체 안내를 표시합니다.
- 원문 입력창에서 `Ctrl+Enter` / `Cmd+Enter`로 번역

자동 감지는 한글·한글 자모가 있으면 한→영, 영문만 있으면 영→한으로 처리합니다. 한국어 고유명사가 섞인 영문은 방향을 수동으로 고정하세요. 숫자와 이모지만 복사한 경우에는 자동 번역하지 않습니다. 한 번에 2,000자까지 처리합니다.

기본 모델 ID는 시작용 예시입니다. 모델 제공 여부, 권한 및 수명 주기는 제공자에 따라 달라지므로 설정에서 실제 사용 가능한 모델 ID로 변경할 수 있습니다. 실제 유료 API 검증을 완료했다는 의미는 아닙니다.

## 로컬 모델

[Ollama](https://ollama.com/download)를 설치하고 원하는 한국어·영어 지원 모델을 내려받아 실행하세요. 예를 들어 다음 명령으로 모델을 설치할 수 있습니다.

```sh
ollama pull qwen3:8b
```

설정에서 **로컬 모델 → Ollama**, 주소 `http://127.0.0.1:11434`, 모델 `qwen3:8b`를 지정합니다. 서버가 켜져 있어야 합니다. 모델 다운로드·실행은 이 앱이 대신 수행하지 않습니다. 메모리가 부족하면 더 작은 모델을 선택하세요.

LM Studio 등은 서버를 먼저 실행하고 **OpenAI 호환**을 선택하세요. 기본 주소 예시는 `http://127.0.0.1:1234/v1`이며 모델 ID는 서버에 로드한 모델의 식별자를 사용합니다. 인증을 사용하는 서버만 API 키를 입력하면 됩니다.

로컬 연결은 `localhost`, `127.0.0.1`, `[::1]`에 한정합니다. 외부 주소나 LAN 서버로 전송하는 설정은 지원하지 않습니다. Ollama의 추론 태그가 응답에 포함되면 완결된 `<think>…</think>` 부분을 제외하고, 미완결 응답은 복사하지 않습니다.

## 용어집

사용자가 지정한 [메이플스토리 클래식 갤러리 용어집](https://gall.dcinside.com/mgallery/board/view/?id=mapleclassic&no=4152)의 약자와 의미를 참고해 주요 사실 매핑을 구성했습니다. 게시글 전문은 배포하지 않습니다. 원문은 앱에서도 열 수 있습니다.

입력에 해당하는 용어를 최대 18개까지 골라 AI에 문맥 힌트로 전달합니다. 용어집을 끄면 용어 매핑과 용어집 전용 지침을 전달하지 않습니다. `CS`, `MM` 같은 다의어는 문맥에 따라 해석하도록 지시하며 단순 치환하지 않습니다. 용어의 포함은 해당 콘텐츠가 실제 게임에 제공된다는 뜻이 아닙니다. AI가 숫자·약자를 항상 정확하게 번역한다는 보장은 없으므로 전송 전에 결과를 확인하세요.

## 개인정보와 저장 위치

자동 감시를 시작하면 복사한 텍스트가 선택한 제공자에 전송됩니다. 게임에 한정해 감지하지 않으므로 민감한 정보를 복사할 때는 감시를 중지하세요. 실제 채팅을 게임으로 전송하는 마지막 동작은 사용자가 수행합니다.

- 클라우드 API 키는 해당 제공자의 고정된 공식 API 주소로만 보냅니다. 로컬 모델은 설정한 루프백 주소로만 보냅니다.
- 키는 Electron `safeStorage`로 암호화한 후 설정 파일에 저장합니다. Windows는 DPAPI, macOS는 Keychain에 기반합니다. 암호화 저장소를 사용할 수 없으면 키를 평문으로 저장하지 않습니다.
- 저장된 API 키는 렌더러에 반환하지 않습니다. 키 입력은 저장 후 지우고, 저장 여부만 표시합니다. 새 키를 입력하기 전에는 기존 키를 화면에서 다시 볼 수 없습니다.
- 번역 기록과 원문은 설정 파일·로그에 저장하지 않습니다. 기록은 앱 종료 시 사라집니다. 실행 중 운영체제의 메모리·클립보드까지 암호화한다는 의미는 아닙니다.
- 설정 파일은 Electron 사용자 데이터 폴더의 `configuration.json`입니다. 일반적으로 Windows는 `%APPDATA%/글클메 채팅 번역기`, macOS는 `~/Library/Application Support/글클메 채팅 번역기` 아래입니다.
- 창을 닫아 트레이에 남으면 앱과 기록이 유지됩니다. **종료**는 트레이 메뉴에서 선택하세요. 설정에서 **창을 닫으면 트레이로**를 끄면 일반 창 종료 동작을 사용합니다.

macOS의 키체인 동작은 코드 서명과 관련이 있습니다. 공개 배포 전에 일관된 Developer ID 서명·공증을 적용해야 업데이트 시 키체인 접근이 안정적입니다. Windows 암호화는 동일 사용자 권한으로 실행되는 다른 프로세스까지 격리하지는 않습니다.

## 빌드와 패키징

```sh
npm test
npm run build
npm start
```

`npm run build`는 타입 검사, 프런트엔드 번들, Electron 메인 프로세스 번들을 생성합니다. `npm start`는 이 빌드를 실행합니다.

각 운영체제에서 아래 명령으로 설치 파일을 만드세요.

```sh
# Windows: x64 설치형 및 포터블 EXE
npm run dist:win

# macOS: Intel + Apple Silicon 유니버설 DMG / ZIP
npm run dist:mac

# 현재 macOS 아키텍처의 .app 폴더만 생성
npm run package:mac
```

결과는 `release/`에 생성됩니다. 화면에 표시하는 프로그램 이름은 **글클메 채팅 번역기**이며, 실행 파일과 macOS 번들의 파일명은 `mscw-chatter`로 고정합니다. 패키지 실행 검증에서 한글 실행 파일 이름을 사용할 때 macOS 시작 오류가 재현되어 영문 파일명을 사용합니다. Windows 시작 메뉴·바로가기와 macOS 표시 이름은 한국어를 사용합니다.

Windows 10은 **64비트**를 대상으로 합니다. 32비트 Windows는 지원하지 않습니다. macOS 패키지의 최소 시스템 버전은 13.0으로 설정했습니다. 운영체제별 빌드와 실제 기기 호환성 테스트는 서로 다른 검증입니다.

`.github/workflows/build.yml`은 main push 또는 수동 실행 시 Windows/macOS에서 단위 테스트·패키징·패키지 실행과 모의 서버 클립보드 통합 테스트를 수행하고 설치 파일을 Actions 산출물로 보관합니다. macOS 앱은 외부 인증서가 필요 없는 개발용 ad-hoc 서명을 적용합니다. Developer ID 서명·공증은 하지 않습니다. Windows도 공개 배포용 코드 서명을 하지 않습니다. 공개 배포에는 Windows 코드 서명과 macOS Developer ID 서명·공증을 별도로 구성하세요. macOS는 빌드 설정의 `mac.identity`를 배포용 인증서 이름으로 교체할 수 있습니다.

## 검증

### GitHub Release 업로드

GitHub에서 버전 태그(예: `v0.1.0`)와 사용법을 적은 Release 초안을 먼저 저장하세요. Actions의 **Publish desktop release → Run workflow**에서 성공한 `Verify and package desktop app`의 실행 ID와 초안의 태그를 입력하면, 해당 빌드의 Windows 포터블 EXE와 macOS 유니버설 앱 ZIP 및 `SHA256SUMS.txt`를 업로드하고 Release를 게시합니다. 태그는 빌드 소스의 `package.json` 버전과 일치해야 합니다. 성공한 main 빌드만 허용하며, 다른 내용의 기존 첨부 파일은 덮어쓰지 않습니다. 별도 개인 토큰은 필요하지 않습니다.

### 로컬 검증

```sh
# 상태 기계, 언어/용어집, 제공자 요청·응답, 키 저장·설정 테스트
npm test

# 먼저 빌드한 뒤 실제 Electron + 클립보드 + 로컬 모의 HTTP 서버 검증
npm run build
npm run test:desktop

# UI만 브라우저에서 미리보기
npm run dev:web

# 소스 ZIP과 UTF-8 변경 파일 목록
npm run package:source
```

네이티브 통합 테스트는 별도 임시 사용자 데이터 폴더와 모의 AI 서버를 사용합니다. 원래 클립보드 형식은 메모리에 보관했다가 복원합니다. 테스트 실행 중에는 클립보드를 직접 변경하지 마세요. `artifacts/desktop-test-results.json`에 검증한 항목과 실행 플랫폼을 기록합니다. 모의 서버 검증은 실제 AI 번역, API 계정 권한, Windows 실행 또는 게임 런타임 검증을 대신하지 않습니다.

현재 의존성의 런타임 감사(`npm audit --omit=dev`)에는 알려진 취약점이 없었습니다. 전체 감사에는 electron-builder의 개발용 간접 의존성 `sprintf-js` 관련 moderate 항목이 남아 있습니다. 배포 앱에는 개발 도구나 npm 모듈을 포함하지 않습니다. 사용하지 않는 구버전으로 빌드 도구를 강제 교체하지 않았습니다.

자세한 책임 분리는 [설계 문서](docs/architecture.md), 참고한 API 규격은 [출처 문서](docs/sources.md)를 확인하세요.
